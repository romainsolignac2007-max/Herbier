# Herbier

Site statique (GitHub Pages) pour apprendre et reconnaître les plantes : recherche, swipe, quizz, classement.

- `index.html`, `app.js`, `style.css` : l'appli. `plantes.js`, `plantes-nouvelles.js`, `tailles.js` : les données des plantes.
- `images/` : une photo par plante (JPEG, côté max 1200 px, 1600 px pour hero/intro/-grand).
- `borne-avis/` : la borne d'avis Solignac (page à part).
- Après une modification de `app.js`, `style.css` ou des fichiers de données, incrémenter le `?v=` dans `index.html`.

## Notes du projet (Obsidian)

- Les notes de ce projet sont dans mon coffre Obsidian, dossier `15-Herbier`. Utilise le skill `obsidian-romain`.
- Au début de chaque session : lis la dernière note de `40-Journal`, `15-Herbier/Avancement.md` et les notes de `90-Decisions` liées à l'Herbier.
- Avant de changer une décision déjà notée dans `90-Decisions`, demande-moi.
- À la fin de chaque session : ajoute un compte rendu dans `40-Journal` (ce qui a été fait, ce qui reste, les problèmes) et mets à jour `15-Herbier/Avancement.md`.
- Une nouvelle plante ajoutée à l'Herbier = une note dans `30-Plantes`.
- Jamais de données personnelles de clients ni de clé API dans Obsidian.
- Si le connecteur `obsidian` ne répond pas (session dans le cloud, ou Obsidian fermé), ne fais pas semblant : dis-le-moi et note le compte rendu à la fin de ta réponse pour que je le colle moi-même.
